# Currency Converter 💱

A simple, fast, and user-friendly **Currency Converter** application that allows users to convert amounts between different world currencies using real-time exchange rates.

---

## 🌟 Features

- **Live Exchange Rates:** Fetches up-to-date currency conversion rates via API.
- **Multi-Currency Support:** Convert between USD, EUR, BDT, INR, GBP, and many other major global currencies.
- **Clean & Responsive UI:** Designed to work seamlessly across desktops, tablets, and mobile devices.
- **Instant Calculation:** Calculates conversions dynamically as inputs change.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **API:** Exchange Rate API
